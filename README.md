# o11 firmware releases

The firmware for the o11 keyboard, one release per version, for the o11 app's Firmware tool: it downloads `o11.signed.bin` from the [latest release](https://github.com/o11hq/o11-releases/releases/latest).

This repo holds only the releases. They are built from the firmware's source by its release workflow and published by Leo alone. Until the o11's own key exists they are signed with MCUboot's test key, and all of them are untested on hardware.
